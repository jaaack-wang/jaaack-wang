**创作缘起：**

所选课程“诗经楚辞选读”之作业也。

**附识：**

下为《祖考皇矣》，乃仿《诗经•鹿鸣之什•天保》所得篇什。《天保》分六段，每段各六句，多四言，偶杂五言，押尾韵，段与段间则择别韵而另押，粗计有六韵部。通览全诗，知是下臣颂君风君之作，《毛诗正义》“天保，下报上也。君能下下，以成其政；臣能归美，以报其上焉，”是之谓也。颂君者，所以风君以厉其远大之宏志而继先王之美政也。因为早作，是以诗中求神祭祀以讫神休、安百姓、定天下，初不可少也。下仿作者，亦因袭而不予改易，或者有风骨留存焉。唯《诗经》所收，去今久远，文字固非漫漶不可识者，然则其语法之规律、表达之习惯、用韵之轨则，则深难悉晓以一二也，遑论模仿乎！瞽者摸象，所触为何即为何；童子学步，亦有以亦趋亦步，安可求全而责备也哉？是以遍查《诗经》，随手摘要，以备所需；以其所需，案诸韵读（如王力《诗经韵读》、王显《诗经韵谱》），用行舍藏；证诸《天保》，文通气顺，最后结构是篇。或可不失仿作之美名耶？



祖考皇矣，顺帝之则<a id="cite1" href="#ref1">[1]</a>。

求民之莫<a id="cite2" href="#ref2">[2]</a>，言新言革<a id="cite3" href="#ref3">[3]</a>。

求民不榖<a id="cite4" href="#ref4">[4]</a>，以近有德<a id="cite5" href="#ref5">[5]</a>。（职部）





祖考皇矣，媚于庶人<a id="cite6" href="#ref6">[6]</a>。

威仪有则，各敬尔身<a id="cite7" href="#ref7">[7]</a>。

邦家之基<a id="cite8" href="#ref8">[8]</a>，保右自天<a id="cite9" href="#ref9">[9]</a>。（真部）





祖考皇矣，筑室崔嵬<a id="cite10" href="#ref10">[10]</a>。

如矢斯棘，如翚斯飞。

如鸟斯革<a id="cite11" href="#ref11">[11]</a>，君泽不摧<a id="cite12" href="#ref12">[12]</a>。（微部）





保艾尔后<a id="cite13" href="#ref13">[13]</a>，申锡无疆<a id="cite14" href="#ref14">[14]</a>。

来假来飨，顾予烝尝<a id="cite15" href="#ref15">[15]</a>。

君子德馨，寿考不忘<a id="cite16" href="#ref16">[16]</a>。（阳部）





维桑与梓，必恭敬止<a id="cite17" href="#ref17">[17]</a>。

似续妣祖，施于民祉。

子子孙孙，勿替引之<a id="cite18" href="#ref18">[18]</a>。（之部）





如瓜之绵<a id="cite19" href="#ref19">[19]</a>，如汉之阔<a id="cite20" href="#ref20">[20]</a>。

如谷风之袭<a id="cite21" href="#ref21">[21]</a>，不日不月<a id="cite22" href="#ref22">[22]</a>。

如明星之烂<a id="cite23" href="#ref23">[23]</a>，视者无不说<a id="cite24" href="#ref24">[24]</a>。（月部）



**余思：**

“看似寻常最奇崛,成如容易却艰辛”。读书不下百遍，则下笔欲有神，其可得乎？



**注释：**

<a id="ref1">[1]  祖考，先祖也。皇者，伟大、光辉貌。《大雅•文王之什•皇矣》：“皇矣上帝！临下有赫。”“祖考皇矣”借其句式而倒转之，隐指先祖为上帝，亦不无先祖崇拜之私意也。则，法度，亦见《皇矣》。</a> [↩](#cite1)



<a id="ref2">[2] 求，探求也。莫通“瘼”，指百姓之苦疾。语见《大雅•文王之什•皇矣》：“监观四方，求民之莫。”</a> [↩](#cite2)



<a id="ref3">[3] 言，语助。新、革，变也。</a> [↩](#cite3)



<a id="ref4">[4] 榖，善也、福禄也。不榖，即民之不善、不德处也。</a> [↩](#cite4)



<a id="ref5">[5] 语见《大雅•生民之什•民劳》：“敬慎威仪，以近有德。”</a> [↩](#cite5)



<a id="ref6">[6] 媚，爱戴也。庶人，百姓也。语见《大雅•生民之什•卷阿》：“蔼蔼王多吉人，维君子命，媚于庶人。”</a> [↩](#cite6)



<a id="ref7">[7] 语见《小雅•节南山之什•雨无正》：“凡百君子，各敬尔身。”此处“各敬尔身”则由“威仪”感染而触发，类于上段之“以近有德”也。</a> [↩](#cite7)



<a id="ref8">[8] 邦家，家国一体之国家也。基，根也。语见《小雅•南有嘉鱼之什•南山有台》：“乐只君子，邦家之基。”</a> [↩](#cite8)



<a id="ref9">[9] 右通“佑”，犹保也。语出《大雅•生民之什•假乐》：“保右命之，自天申之。”</a> [↩](#cite9)



<a id="ref10">[10] 筑室，为先祖构筑纪念堂以承其休其泽也。见《小雅•鸿雁之什•斯干》：“似续妣祖，筑室百堵。”崔嵬，代指山也。见《小雅•谷风之什•谷风》：“习习谷风，维山崔嵬。”</a> [↩](#cite10)



<a id="ref11">[11] 棘，犹箭矢之棱角也。翚，野鸡。革通“翮”，鸟振翅飞也。语出《小雅•鸿雁之什•斯干》：“如跂斯翼，如矢斯棘，如鸟斯革，如翚斯飞，君子攸跻。”</a> [↩](#cite11)



<a id="ref12">[12] 摧，灭也。不摧，即先祖福泽永世而不斩也。语出《大雅•荡之什•云汉》：“胡不相畏？先祖于摧！”</a> [↩](#cite12)



<a id="ref13">[13] 艾，养也。语见《小雅•南有嘉鱼之什•南山有台》：“乐只君子，保艾尔后。”</a> [↩](#cite13)



<a id="ref14">[14] 申，复也。锡，赐也。申锡，反复赏赐也。语见《颂•商颂•烈祖》：“申锡无疆，及尔斯所。”</a> [↩](#cite14)



<a id="ref15">[15] 假，至也。烝，冬祭。尝，秋祭。语出《颂•商颂•烈祖》：“来假来飨，降福无疆。顾予烝尝，汤孙之将。”</a> [↩](#cite15)



<a id="ref16">[16] 忘通“亡”，终止也。语见《风•秦风•终南》：“佩玉将将，寿考不忘。”</a> [↩](#cite16)



<a id="ref17">[17] 桑、梓，父母手植者也，子孙见及，如睹先人，必恭必敬。然之桑梓者，亦不无喻指先祖之政治遗产与道德风范。此两句，语见《小雅•节南山之什•小弁》。</a> [↩](#cite17)



<a id="ref18">[18] 替，废止。引，延续。勿替引之，勿废止而延续之之意也。此两句，语见《小雅•谷风之什•楚茨》。</a> [↩](#cite18)



<a id="ref19">[19] 语出《大雅•文王之什•绵》：“绵绵瓜瓞，民之初生”。喻指祖考功德之久远也。</a> [↩](#cite19)



<a id="ref20">[20] 语出《风•周南•汉广》：“汉之广矣，不可泳思”。喻指祖考功德之广泛也。为协韵，是以易“广”为“阔”矣。</a> [↩](#cite20)



<a id="ref21">[21]  “谷风”可见《风•邶风•谷风》《小雅•谷风之什•谷风》，然此处但指山谷不绝之风也。</a> [↩](#cite21)



<a id="ref22">[22] 语出《风•王风•君子于役》：“君子于役，不日不月”。此处转其意而用之。</a> [↩](#cite22)



<a id="ref23">[23] 语出《风•郑风•女曰鸡鸣》：“子兴视夜，明星有烂。”</a> [↩](#cite23)



<a id="ref24">[24] 说通“悦”，愉悦貌。</a> [↩](#cite24)
